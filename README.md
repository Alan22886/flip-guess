# 滑动猜词

中文猜词游戏。设置主要用竖屏，横屏确认规则后开始，游戏和结算使用横屏。支持分组或个人对战、词库管理、历史记录以及离线运行。

[打开游戏](https://alan22886.github.io/flip-guess/)

## iPhone 安装

1. 用 Safari 联网打开游戏网址。第一次打开后，竖屏滑到「请横屏后开始」，松手后再向上划一次，展开记录与备份区。等待「离线资源已就绪」。
2. 点 Safari 的「分享」→「添加到主屏幕」。如系统显示「作为 Web App 打开」开关，请打开它，再点「添加」。
3. 从主屏幕图标打开一次，确认没有 Safari 地址栏。建议在这个入口再确认「离线资源已就绪」，然后用飞行模式复查。
4. 旋转 iPhone 前请检查系统竖排方向锁定。旋回竖屏会暂停，重新横屏后需手动恢复。

## 开局和恢复

- 游戏记住上次开局的模式、分组、昵称、时长和词库。设置和未完成进度保存在当前安装环境。
- 横屏开局前会估算词库余量，按每人约每 8 秒消耗一个词。可以补选类别，或允许在新词用尽后复用所选类别的旧词。
- 每人时长可选 1 到 2.5 分钟，每档 30 秒。
- 每人每轮前 3 次跳过免费，之后每次跳过扣 1 分；跳过区会显示剩余免费次数。
- 猜词时可点按左右半屏，也可横滑。左滑让蓝区铺开并判猜中，右滑让红区铺开并判跳过。
- 描述时说出了词里的字，点「犯规」：这个词作废，不加分也不扣分，也不占免费跳过次数，可以撤销。
- 误关后点「继续未完成对局」，已完成回合会保留，首个未完成的回合从头开始。该对局已展示过的词不会重抽。主动结束或放弃进度会保存中断日志。

## 开发、测试和发布

需要 Node.js 24。运行时只用原生 HTML、CSS 和 JavaScript，所有游戏资源随站点发布。

```sh
npm ci
npx playwright install chromium webkit
npm test
npm run build
```

本地测试用 iPhone 尺寸运行 Chromium 和 WebKit，测试服务地址为 `http://127.0.0.1:4173/flip-guess/`。单独预览可在构建后运行 `node tests/server.mjs`。网址后加 `?quick` 时每人时长变为 3 秒，供测试和真机检查使用，界面上不提供这一档。如同目录存在原始 v59 HTML，迁移测试会直接打开它、完成真实对局并下载两种旧备份，再用全新浏览器环境导入、比对。原始 HTML 和备份由 Git 忽略。

更改 `index.html`、`css/style.css` 或 `js/`，通过测试后提交并推送到 `main`。仓库的 Settings → Pages → Source 应为 GitHub Actions。工作流只发布 `dist/`，可在 Actions 查看部署。在独立安装环境中先联网打开以检查更新。新版完整下载并校验后会等待旧页面关闭。结束对局后关闭游戏页面并再次打开，即可使用已成功安装的新版本。

构建将 HTML、样式、词库和脚本合成同一页面，Service Worker 对发布资源逐个校验，按部署子路径隔离缓存。激活新版后清理该路径的旧缓存。数据使用独立的 localStorage，更新缓存不修改数据。旧的同源记录键可读取，导入记录以一次写入提交。记录和词库使用同步存储，数据持续增长会增加写入开销，并可能达到浏览器配额。写入失败会在页面提示。建议定期导出两份备份，并在一个窗口进行编辑和对局。Safari 与主屏幕 Web App 的存储可能隔离，iOS 也可能回收站点数据。

## 实机验收

Playwright 模拟触屏、方向、离线和版本切换。iPhone 实机仍需确认主屏幕安装、无地址栏启动、灵动岛边距、系统分享和文件选择器、飞行模式冷启动，以及扬声器中的音色和音量。
